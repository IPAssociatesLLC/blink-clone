# Blink.new Clone

A pixel-perfect clone of [blink.new](https://blink.new) - The #1 AI Agentic Coding Platform.

- `index.html` - Complete landing page with all sections
- `styles.css` - Full responsive CSS with light/dark theme support
- `script.js` - Interactive features (theme toggle, FAQ, tabs, animations)
- `assets/favicon.svg` - Blink favicon

- Responsive design (mobile, tablet, desktop)
- Light/Dark/System theme toggle with localStorage persistence

- FAQ accordion with smooth animations

- Keyboard shortcut (Ctrl/Cmd + K to focus input)
- Mobile hamburger menu
